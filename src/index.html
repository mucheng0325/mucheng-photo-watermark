使用说明

  1. 「选择照片 / 文件夹」（Ctrl+O）或直接拖入 → 自动读取 EXIF 相机参数；导出 Ctrl+E，←/→ 切换照片
  2. 字体可直接选本机字体库中的任意字体，列表里每一行都用该字体自身字形预览；默认只列中文字体（点「全部」看日文 / 西文），内置普惠体随应用分发，换机也一致
  3. 右侧六个标签页：版式（含九宫格位置与水印大小）、文字、参数、品牌（含分隔竖线）、版权、输出；滑杆右侧的数值可以点击后键入精确值
  4. 版式里的「白色边框 · 底部题注」会在照片外圈加一圈白边、并在底部白边上写参数，白边宽度可调；白底上文字与 Logo 自动转深色
  5. 竖线颜色可选主题色 / 自定义 / 品牌色 / 文字色；文字颜色、字号、字重、字距均可调
  6. 界面主题与界面主题色在顶栏「设置」中调整，与水印主题色（版式页签）互相独立
  7. 预览区：滚轮缩放、按住拖动平移、双击复位，「1:1」按原始像素查看，快捷键 +/-/0/1

提示：图片不存在 EXIF 时，可在「参数 → 参数行覆盖」手写内容。
