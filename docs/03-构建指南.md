# 构建指南

## 1. 环境

| 依赖 | 版本 | 说明 |
| --- | --- | --- |
| Node.js | ≥ 18 | 构建脚本、验收脚本 |
| Rust | ≥ 1.77 | GNU 工具链 `x86_64-pc-windows-gnu` |
| MinGW-w64 | — | 提供 `windres` / `dlltool` / `as`；推荐 [w64devkit](https://github.com/skeeto/w64devkit) |
| WebView2 Runtime | Evergreen | 运行期依赖，Win10/11 一般自带 |

本项目不使用 MSVC，也不需要 Visual Studio。

---

## 2. 一条命令

```bash
npm run build
```

内部流程（`scripts/build-win.js`）：

1. 把 `W64DEVKIT`（默认 `D:/SOFT/w64devkit`，可用环境变量改）加入 PATH
2. `cargo build --release`
3. 复制 `target/release/exif-cam.exe` → `build-out/暮呈照片水印工作台/暮呈照片水印工作台.exe`
4. 复制 `target/release/WebView2Loader.dll`
5. 生成 `使用说明.txt`，并带上 `LICENSE`

产物：

```
build-out/暮呈照片水印工作台/
├─ 暮呈照片水印工作台.exe      ~11 MB
├─ WebView2Loader.dll          160 KB
├─ 使用说明.txt
└─ LICENSE
```

首次运行后多出 `data/`。

## 3. 手工构建（等价）

```bash
cd src-tauri
export PATH="/d/SOFT/w64devkit/bin:$PATH"
cargo build --release
```

产物 `target/release/exif-cam.exe`。**必须**与 `target/release/WebView2Loader.dll` 放在一起，
否则双击会以 `0xC0000135`（STATUS_DLL_NOT_FOUND）静默退出。

---

## 4. 关于可执行文件名

`src-tauri/Cargo.toml` 的 `[package] name` 与 bin 名保持 ASCII（`exif-cam`）。

**不要**把 `[[bin]] name` 改成中文：实测虽然编译通过，但 `tauri-build` 经 `windres`
生成的中文目标文件名会让成品在加载阶段直接退出 —— 进程进不到 `main`，没有日志、
没有窗口、退出码 `0xC0000135`，排查成本很高。中文名由构建脚本在构建后重命名，
`tauri.conf.json` 的 `mainBinaryName` 已同步设为中文，保证 `tauri build` 打包时一致。

---

## 5. 前端资源

`src-tauri/tauri.conf.json` 的 `frontendDist` 直接指向 `../src`：

```json
"build": { "frontendDist": "../src" }
```

没有中间产物目录，也没有「同步脚本」。改完前端**必须**让 Tauri 重新嵌入资源：

```bash
cd src-tauri && cargo clean -p exif-cam && cargo build --release
```

只跑 `cargo build` 有时不会把 `src/` 的改动算作重新编译的触发条件，会出现「代码改了、
exe 里还是旧的」——这是 `tauri-build` 的缓存行为，不是代码问题。

## 6. 字体子集化

`src/fonts/` 里的普惠体是子集版本（ASCII + GB2312 全区，约 7554 字），4 档合计 4.7MB。
完整字体在 `resources/fonts-full/`（未纳入版本控制）。

重新生成：

```bash
python scripts/subset_fonts.py
```

依赖 `fonttools`（`pip install fonttools brotli`）。

---

## 7. 图标

```bash
python scripts/make_logo.py
```

生成：

- `src/assets/logo-light.png` / `logo-dark.png`（顶栏用，透明底，512²）
- `src-tauri/icons/icon.ico`（多尺寸，exe 图标）
- `src-tauri/icons/icon.png`

依赖 `Pillow`。源图在 `resources/logo-source.png`（若有）。

## 8. 验收

```bash
npm test
```

| 脚本 | 内容 | 项数 |
| --- | --- | --- |
| `tests/render.test.js` | 水印合成几何、白边、墨迹位置、配置迁移 | 31 |
| `tests/ui.test.js` | 主题三档、窗口控制、色板、`[hidden]` 可见性 | 40 |
| `tests/app.test.js` | 真机：绿色目录、配置镜像、重启持久化、窗口行为 | 47 |

`app.test.js` 需要 `src-tauri/target/release/` 下同时存在 `exif-cam.exe` 与
`WebView2Loader.dll`，并会占用 9488 / 9489 端口做 CDP 调试。

无头脚本依赖本机 Chrome（默认 `C:/Program Files/Google/Chrome/Application/chrome.exe`），
路径不同的请改脚本顶部的 `CHROME` 常量。

---

## 9. 已知限制

- 只构建 Windows x64
- GNU 工具链下 `WebView2Loader.dll` 为动态链接，无法真正做成单文件
- `bundle.active = false`：本项目按绿色版分发，不生成 NSIS / MSI 安装包
