# 使用手册

## 1. 界面分区

```
┌────────────────────────────────────────────── 顶栏 ──────────────────────────────────────────────┐
│ Logo 照片水印工作台        …        选择照片  选择文件夹  导出全部  ?  ◐  设置  ─ □ ✕ │
├──────────────┬────────────────────────────────────────────┬──────────────────────────────────────┤
│  照片清单     │              预览画布                       │  参数面板（6 个页签）                 │
│  （可拖入）   │  滚轮缩放 · 空格拖动 · 双击复位              │  版式 / 文字 / 参数 / 品牌 / 版权 / 输出 │
└──────────────┴────────────────────────────────────────────┴──────────────────────────────────────┘
```

- 顶栏空白处按住可拖窗，双击切换最大化；右上三颗按钮是最小化 / 最大化 / 关闭
- 窗口四边 5px 是缩放热区（无边框窗口需要自己画热区，否则拉不动大小）

---

## 2. 载入照片

三种方式：

1. 点顶栏「选择照片」多选
2. 点「选择文件夹」批量导入
3. 直接把文件拖进左侧清单

支持 JPEG / PNG / WebP / TIFF。EXIF 会自动解析，读不到相机的照片也能用，只是参数行会变少。

清单里每张照片左侧显示序号、右侧显示色彩 / 大小，点选切换预览。

---

## 3. 调水印

右侧六个页签：

**版式**
- 五种模板：悬浮卡片 / 底部通栏 / 右侧竖排 / 四角极简 / 白色边框
- 九宫格定位：任意位置的 Logo 尺寸、竖线长度、字号完全一致
- 水印大小：滑杆右侧数值可点击，直接键入精确倍率
- 「白色边框」独有：白边宽度 0.8%–8%（相对照片宽度），底部留白自动按白边 ×2.6 加高

**文字**
- 字体：内置普惠体 4 档 + 本机字体库（可按中文 / 日文 / 韩文 / 拉丁筛选与搜索）
- 主行 / 副行字号倍率、字重、颜色、透明度
- 数字等宽、参数分行显示

**参数**
- 逐项开关：机型、镜头、光圈、快门、ISO、焦距、等效焦距、拍摄时间
- 参数分隔符（`·` / `|` / `/` / 空格）

**品牌**
- 默认按 EXIF 自动识别，也可以点品牌卡手动换（比如索尼拍的想用尼康标识）
- 品牌标识使用各家原厂配色，不跟随软件主题色
- 支持上传自定义标识（单色 / 彩色）

**版权**
- 自由文本，默认留空
- 预设按钮：`© {year}`（自动带当前年份）

**输出**
- 输出目录、文件名规则、最长边限制、水印不透明度与背景样式

---

## 4. 缩放与查看

| 操作 | 效果 |
| --- | --- |
| 滚轮 | 以光标为中心缩放 |
| 空格 + 拖动 | 平移画布 |
| 双击画布 | 复位到「适配窗口」 |
| `←` `→` | 上一张 / 下一张 |
| `+` `-` | 放大 / 缩小 |
| `0` | 适配窗口 |
| `1` | 100% 原始像素 |

预览按当前缩放倍率动态提升渲染分辨率（长边上限 3200），放大看细节不糊。

---

## 5. 导出

- 单张：清单右键 → 导出当前
- 全部：顶栏「导出全部」，弹出进度模态，显示逐张进度、剩余时间，可随时取消
- 完成后可直接点「打开输出文件夹」

导出分辨率按「最长边限制」等比缩放；选「原始尺寸」则按原图输出。
水印全部尺寸以图片宽度为基准等比计算，所以预览与导出结果一致。

快捷键 `Ctrl+E` 等价于「导出全部」，`Ctrl+O` 等价于「选择照片」。

---

## 6. 设置

- **主题模式**：跟随系统 / 浅色 / 深色（顶栏那颗按钮按这三档循环）
- **界面主题色**：8 个预设 + 自定义，只影响界面，不影响导出图像
- **数据与存储**：显示真实的数据目录与配置文件路径（点击可复制），一键打开目录 / 查看日志

水印主题色在「版式」页签单独设置，与界面主题色互不影响。

---

## 7. 常见问题

**照片参数显示不全**

原图没有对应 EXIF 字段（微信 / 社交平台转存常会抹掉）。这是数据缺失，不是解析失败。

**品牌识别错了**

点「品牌」页签的品牌卡手动指定，会覆盖自动识别结果并记住。

**导出后水印比预览大 / 小**

检查「输出」里的最长边限制。预览按视口缩放，导出按目标分辨率重新合成，两者按比例应当一致。

**换了电脑字体不一样**

本机字体库读的是系统已安装字体，不同机器可选项不同。要固定效果，用内置普惠体。

**软件打不开 / 配置丢了**

先看 `data/logs/app.log`；配置在 `data/config.json`，详见
[绿色版与数据目录](02-绿色版与数据目录.md)。
